# Fur-nished
*Elevated living for cats and their humans.*

Shopify Online Store 2.0 theme. Palette: background #FAF8F5, accent terracotta #C86D51 (hover warm oak #A67B5B), text #2C2C2C. Fonts: Playfair Display (headings) + Lato (body). All are editable in Theme settings.

## Preview
    shopify theme dev --store your-store.myshopify.com

## Upload
    shopify theme push --unpublished --store your-store.myshopify.com

## Products
1. Admin > Products > Import > `products.csv` (placeholder prices/descriptions, edit freely).
2. Upload the matching photos from `product-images/` to each product (CSV import needs public image URLs, so they are added by hand).
3. Create a menu named `main-menu` (Shop all, Cat Beds, Our story) and `footer`.
4. Create a page "Our story" (the home page buttons link to it).
